健康保险智能咨询平台 - 项目说明
========================================

本项目是一个基于知识图谱和大语言模型的健康保险智能咨询平台，提供保险咨询、产品查询、争议案例处理等智能化服务。

项目结构说明：
----------------

1. app/ - 后端服务目录
   基于FastAPI框架构建的后端服务，包含：
   - API接口定义 (api/endpoints.py)
   - 核心业务逻辑服务 (services/)
   - 知识图谱服务 (graph_service.py)
   - 大语言模型服务 (llm_service.py)
   - 问答服务 (qa_service.py)
   - 视觉识别服务 (vision_service.py)
   - 应用配置管理 (core/config.py)
   - 知识图谱构建工具 (build_kg.py)

2. 前端/ - 前端界面目录
   现代化Web前端应用，提供用户交互界面：
   - 主页面 (index.html) - 响应式设计，支持移动端和桌面端
   - 应用逻辑 (app.js) - 页面交互和功能实现
   - API调用封装 (api.js) - 后端服务通信
   - 工具函数 (utils.js) - 通用工具函数集合
   - 支持智能问答、产品查询、争议案例浏览等功能

3. data/ - 数据存储目录
   用于存放项目相关的数据文件，如：
   - 知识图谱数据
   - 训练数据集
   - 配置文件等

4. fine_tuning/ - 模型微调目录
   用于存放模型微调相关的文件和脚本：
   - 微调训练脚本
   - 模型配置文件
   - 评估指标等

技术栈：
--------
- 后端：Python, FastAPI, Neo4j图数据库
- 前端：HTML5, CSS3, JavaScript, Tailwind CSS
- AI模型：阿里云百炼平台(Qwen大模型)
- 可视化：Three.js, Plotly.js

主要功能：
--------
1. 智能咨询 - 基于知识图谱的保险问题解答
2. 产品查询 - 保险产品搜索和对比
3. 争议处理 - 保险争议案例浏览和分析
4. 图像识别 - 医疗单据和图像分析
5. 知识管理 - 保险知识图谱构建和维护
