# 健康保险智能咨询平台 - 前端

## 项目概述

本项目是健康保险智能咨询平台的前端界面，提供用户友好的交互体验，包括保险咨询、产品查询、争议案例浏览等功能。前端采用现代化Web技术构建，具有响应式设计，适配不同设备屏幕。

## 文件详细说明

### index.html - 主页面文件
这是整个应用的入口HTML文件，包含了所有页面视图和UI组件：
- 响应式设计，适配移动端和桌面端
- 使用Tailwind CSS作为主要样式框架
- 集成了Three.js和Vanta.js实现动态背景效果
- 包含多个功能模块页面：
  - 智能问答机器人(chat)
  - 保险产品查询(products)
  - 争议案例(dispute)
  - 用户反馈(feedback)
- 引入了所有必需的外部库和字体资源

### app.js - 主要应用逻辑
负责处理前端的主要交互逻辑和功能实现：
- 页面切换和导航管理
- 各个功能模块的初始化和事件处理
- 智能问答机器人的对话管理
- 保险产品搜索和展示
- 争议案例浏览和管理
- 用户反馈提交和展示
- 文件上传和处理功能
- 数据可视化图表渲染

### api.js - API接口调用封装
封装了所有与后端服务通信的API调用：
- 基于fetch API的统一请求封装
- 错误处理和日志记录
- 问答接口(流式和非流式)
- 保险产品查询接口
- 图片分析接口
- 争议案例相关接口

### utils.js - 工具函数集合
提供了应用中通用的工具函数：
- 时间格式化
- 防抖和节流函数
- DOM操作辅助函数
- 数据处理和验证函数
- 文件处理相关函数
- 表单验证和数据序列化
- 数学计算和统计函数
- 存储(localStorage)操作函数

## 技术栈

- **HTML5/CSS3** - 页面结构和样式
- **JavaScript (ES6+)** - 交互逻辑
- **Tailwind CSS** - CSS框架
- **Three.js/Vanta.js** - 动态背景效果
- **Marked.js** - Markdown渲染
- **Plotly.js** - 数据可视化
- **SheetJS (xlsx)** - Excel文件处理

## 主要功能模块

1. **智能问答机器人**
   - 实时流式对话
   - 支持文本和图片输入
   - 对话历史记录管理

2. **保险产品查询**
   - 关键词搜索保险产品
   - 产品详情展示
   - 保险责任和条款对比

3. **争议案例浏览**
   - 案例分类展示
   - 案例详情查看
   - 案例搜索功能

4. **用户反馈系统**
   - 用户评价和建议提交
   - 反馈列表展示
   - 互动评论功能

## 部署说明

前端可以直接通过浏览器打开index.html文件运行，但需要确保：
1. 后端服务正常运行且可访问
2. 网络连接正常以加载CDN资源
3. 浏览器支持所需Web API
