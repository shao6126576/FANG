# 健康保险智能咨询平台 - 后端应用

## 项目概述

本项目是一个基于知识图谱和大语言模型的健康保险智能咨询平台，主要功能包括：
- 健康保险相关问题智能问答
- 保险产品查询与推荐
- 保险图像分析
- 知识图谱构建与查询

## 目录结构
```
app/
├── api/          # API接口定义
├── core/         # 核心配置和提示词
├── models/       # 数据模型定义
├── services/     # 核心业务逻辑服务
├── build_kg.py   # 知识图谱构建脚本
└── main.py       # 应用入口文件
```

## 文件及目录详细说明

### main.py - 应用入口文件
FastAPI应用的主入口，负责：
- 初始化FastAPI应用实例
- 配置CORS跨域策略
- 注册API路由
- 配置静态文件服务
- 启动应用服务器

### api/endpoints.py - API接口定义
定义了系统的RESTful API接口：
- `/ask` - 用户问题回答接口
- `/ask/stream` - 流式回答接口
- `/products` - 保险产品搜索接口
- `/analyze-image` - 图像分析接口

### core/ - 核心配置目录
#### config.py - 配置管理
使用Pydantic管理应用的所有配置项：
- Neo4j数据库连接配置
- 阿里云百炼平台API密钥和基础URL
- 应用运行参数（主机、端口、调试模式等）

#### prompts.yaml - 提示词模板
定义各种场景下的LLM提示词模板：
- 系统角色设定
- 关键词提取模板
- 不同专家角色的问答模板

### models/schemas.py - 数据模型
使用Pydantic定义的数据传输对象（DTO）：
- QuestionRequest - 用户问题请求体
- AnswerResponse - 回答响应体
- GraphQueryResult - 图谱查询结果

### services/ - 核心服务层
#### qa_service.py - 问答服务
核心问答逻辑处理：
- 接收用户问题
- 调用关键词提取
- 协调图谱检索和大模型回答生成
- 返回最终答案

#### graph_service.py - 知识图谱服务
负责与Neo4j图数据库交互：
- 保险产品搜索
- 疾病保障信息查询
- 适用药物查询
- 知识图谱路径查询

#### llm_service.py - 大语言模型服务
集成阿里云百炼平台的大模型服务：
- 使用Qwen模型进行问答
- 关键词提取
- 多专家视角回答生成
- 提示词管理和优化

#### vision_service.py - 视觉识别服务
专门处理图像相关的分析任务：
- 医疗单据识别
- 图像内容分析
- 医疗图像理解

### build_kg.py - 知识图谱构建工具
用于构建和维护医疗知识图谱：
- 保险产品数据导入
- 疾病、药品等实体关系建立
- 数据清洗和预处理
- 批量导入Neo4j数据库

## 技术栈

- **后端框架**: FastAPI
- **图数据库**: Neo4j
- **大语言模型**: 阿里云百炼平台(Qwen)
- **数据处理**: Pandas, Py2Neo
- **配置管理**: Pydantic
